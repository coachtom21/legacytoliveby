# Research equality convention (non-negotiable)

**Source:** Client directive — Human Gold Rush testnet / gameplay integrity (2026).

## Rule

In **any calculation, formula, allocation identity, or cross-rail comparison** (USD, YAM, BTC, XP, NWP, $30 patterns, $10.30 community lines, etc.):

| Do **not** use | Use instead |
|----------------|-------------|
| `=` (legal / convertible equals) | `≐` (dotted equals — research comparison only) |
| or, where preferred in prose | `≈ᵣc` / “research-comparable to” |

**Meaning:** the sides may be **compared for study**. They are **not** interchangeable money, redeemable value, or a contractual conversion rate.

Examples:

```text
$10 COGS + $9.70 seller margin + $10.30 community value ≐ $30
$5 + $4 + $1 + $0.30 ≐ $10.30
1.00 USD ≐ 4.76190476 × 10^20 XP   (comparison scale only — no redemption)
NWP ≐ XP × W_net
```

## Scope

Applies to:

- Public UI copy that shows formulas  
- Lesson pages, PDFs, schema docs, GitHub gameplay rules  
- Simulations (`.py`), ledger comments, admin warnings  
- Woo / HBC / Discord explanations of accounting patterns  

Does **not** apply to:

- Programming operators (`===`, `==`, CSS, SQL)  
- Ordinary English (“XP means Experience Presence”)  
- HTML attributes or URLs  

## Seeking Gratitude vs YAM-is-On

Both may display the same **$30 / $10.30 pattern** using `≐`.  
Only YAM-is-On moves fiat/crypto. Seeking Gratitude remains XP-only.  
`≐` must never be read as “XP can be cashed out as dollars.”

## Cursor / Utsav standing instruction

> When writing or editing Human Gold Rush formulas, never use a plain equals sign between monetary symbols, XP, YAM, BTC, or NWP. Always use dotted equality `≐` (or explicit “research-comparable”) so the protocol remains a nonconvertible behavioral game, not a financial instrument.
